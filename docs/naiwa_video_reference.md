# 奶蛙捧腹大笑的视频参考与游戏时间线

用户提供的短视频约 21.7 秒、约 30 fps。可见动作不是单一站姿：开口后仰大笑，弯腰捧腹，再起身，双手短暂抱头，继续笑至倒地，随后恢复平静。游戏需要在约 3.4 秒的可玩大招内压缩这一节奏，并保留用户第三张图所示的笑后伸掌动作。视频画面只作动作参考，不直接放入游戏。

| 游戏帧（60 fps） | 演出 |
| --- | --- |
| 0–35 | 大招切入：捧腹大笑的大幅角色图与台词 |
| 36–75 | 捧腹笑，身体按帧上下起伏；金色音波开始扩散 |
| 76–99 | 双手抱头大笑；与捧腹姿势做短过渡 |
| 100–159 | 再次捧腹笑，持续产生音波；多个波环叠加 |
| 160–177 | 笑倒在地，腹部朝外；结尾强音波伤害 |
| 178–203 | 起身摆出用户第三张图的宽腿伸掌姿势 |

音波由透明特效图放大、淡出和几何圆弧叠加，每 12 帧形成一次可见脉冲。视频和用户图片里的奶蛙主要是黄色、浅色腹部、深色手脚、闭眼大笑；后续美术精修以这些识别点为准。
